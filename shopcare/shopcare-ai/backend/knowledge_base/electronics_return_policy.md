# Electronics & Accessories Return Policy

## Return Window
- **Smartphones, Tablets & Laptops:** 10-day return window from the date of delivery for manufacturing defects, damaged-on-arrival items, or wrong items shipped.
- **Audio & Electronics Accessories (Earbuds, Chargers, Cables, Power Banks, Cases):** 15-day return window from the date of delivery.
- Items must be returned with original packaging, serial/IMEI match, and included accessories.

## Eligibility Conditions
- Orders must be in `delivered` status. Orders currently in `processing` or `shipped` status cannot be refunded through the post-delivery return flow; customers may request cancellation or wait for delivery.
- Return requests submitted **after** the item's `return_window_days` window has expired are ineligible and must be declined with the exact delivery date and window explanation.

## Refund Thresholds & Human Review
- Eligible electronics/accessory refunds of **₹5,000 or less** (`<= ₹5,000`) within the return window may be processed automatically upon server-side verification.
- Any refund request **above ₹5,000** (`> ₹5,000`) requires mandatory **human staff escalation** and review before approval or payout.
