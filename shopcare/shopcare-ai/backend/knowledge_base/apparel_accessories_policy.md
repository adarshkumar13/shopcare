# Apparel, Footwear & Home Goods Return Policy

## Return Window
- **Apparel & Footwear:** 30-day return window from the date of delivery, provided tags are intact and the item is unworn/unwashed.
- **Home & Lifestyle Accessories:** 15-day return window from the date of delivery.
- **Personal Care & Consumables:** Non-returnable once opened, unless damaged or expired upon delivery.

## Damaged or Defective Items
- If an item arrived damaged, defective, or incorrect, customers are eligible for a full refund of the unit price paid (up to the order's `total_amount`) within the applicable return window.
- Requests beyond the return window (`return_window_days`) are not eligible for automated refunds.
